* **Features:** Built a custom admin CMS for inventory/banner management. Developed a dynamic cart system using HTMX for seamless state updates without heavy JS frameworks. Integrated the **Monobank API** for secure checkout and configured automated Telegram alerts for new orders.

📂 **"Minority" Multiplayer Game Bot**
*A stateful, real-time multiplayer betting and elimination game built entirely within Telegram.*
* **Stack:** Python, aiogram 3, aiogram-dialog, Redis, Tortoise-ORM, PostgreSQL.
* **Features:** Engineered complex multiplayer lobby matchmaking using shared memory states. Designed real-time game loops handled via asynchronous background tasks with strict atomic counters. Utilized **Redis pipelines** for high-efficiency state caching, synchronized timer thresholds, and automated dice-duel resolution for final 1v1 endgames.

📂 **Esports Analytics & Dynamic Scoreboard Generator Engine**
*An automated scraping and visual parsing worker for competitive CS:GO/CS2 metrics.*
* **Stack:** Python, aiogram 3, cloudscraper, Tortoise-ORM, PostgreSQL, Headless Chromium, CairoSVG.
* **Features:** Built an automated ETL pipeline that bypasses Cloudflare protections via customized session masking to fetch real-time tournament and player data from HLTV. Integrated a headless Chromium driver to capture raw data matrices, injecting them into localized HTML/CSS canvases to dynamically render premium high-resolution infographic scoreboards directly inside chat interfaces.

📂 **Bubble Coffee Namur**
